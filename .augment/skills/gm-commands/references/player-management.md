# 玩家管理指令

## 查詢類

### mstat — 查看角色詳細資料（L_ANG）
```
mstat <玩家名稱>
mstat <怪物名稱>
```
顯示角色的完整屬性、技能、魔法效應、裝備等所有資訊。
包括 str/int/wis/dex/con、HP/MP/MV、位置、陣營值、旗標等。

### mfind — 依名稱搜尋怪物索引（L_ANG）
```
mfind <關鍵字>
```
搜尋 mob 索引中符合關鍵字的怪物，列出其 vnum 與名稱。

### mwhere — 找出怪物目前所在位置（L_ANG）
```
mwhere <怪物名稱>
```
列出該種怪物目前在遊戲世界中的所有出現位置（房間名稱與 vnum）。

### mlist — 列出怪物索引（L_ANG）
```
mlist
mlist <關鍵字>
```

### mlevel — 列出指定等級範圍的怪物（L_ANG）
```
mlevel <最低等級> <最高等級>
```

## 懲罰類

### freeze — 凍結玩家（禁止輸入指令）（L_SUP）
```
freeze <玩家名稱>
```
被凍結的玩家無法輸入任何指令。再次對已凍結的玩家執行 `freeze` 可解除。

### silence — 禁止頻道發言（L_PC 以上）
```
silence <玩家名稱>
```
禁止玩家使用公開頻道發言。

### noemote — 禁止動作指令（L_DEI）
```
noemote <玩家名稱>
```
禁止玩家使用 emote（情感表達）指令。

### notell — 禁止私訊（L_PC 以上）
```
notell <玩家名稱>
```
禁止玩家使用 tell 私訊功能。

### jail — 關進監獄（L_SUP）
```
jail <玩家名稱>
```
將玩家強制移動至監獄房間。

### pardon — 赦免玩家（L_DEI）
```
pardon <玩家名稱>
```
清除玩家的 wanted（通緝）狀態，或其他罪行記錄。

### deny — 禁止登入（L_SUP）
```
deny <玩家名稱>
```
永久禁止指定玩家帳號登入遊戲。

### slay — 殺死角色（L_DEI）
```
slay <玩家或怪物名稱>
```
立即奪去目標生命，對象等級必須比執行者低。
與 `purge` 不同：slay 會留下屍體。

### nuke — 完全刪除角色（L_GOD）
```
nuke <玩家名稱>
```
從遊戲中永久刪除角色存檔（極度危險，不可逆）。

## 提升/調整類

### advance — 升降等級（L_GOD）
```
advance <玩家名字> <等級>
```
強制將玩家升到或降到指定等級（上限 100）。

### habilitate — 授予神族權限（L_GOD）
```
habilitate <玩家名字> <等級>
```
將玩家提升到神族等級（101+），授予管理員身分。

### trust — 設定信任等級（L_GOD）
```
trust <玩家名字> <等級>
```
設定玩家的實際信任等級（不改變顯示等級，僅影響可用指令範圍）。

### restore — 回復狀態（L_DEI）
```
restore <玩家>       → HP/MP/MV 全滿
restore !<玩家>      → 移除所有魔法效應
```

### lset — 設定技能熟練度（L_DEI）
```
lset <玩家> <技能名稱> <熟練度(0-100)>
```
直接設定玩家某技能的熟練度，0 表示移除。

## 移動類

### transfer — 召喚玩家（L_DEI）
```
transfer <玩家>
transfer all
```

### goto — 傳送自己（L_ANG）
```
goto <房間 vnum>
goto @<玩家名稱>
```

### at — 在指定地點執行指令（L_ANG）
```
at <房間 vnum> <指令>
at @<玩家名稱> <指令>
```
範例：`at @jake mstat jake` → 在 jake 位置查看 jake 狀態

---

## 監視類

### snoop — 監聽玩家輸入輸出（L_SUP）
```
snoop <玩家名稱>
```
觀看玩家所有輸入及收到的輸出。再次執行可取消。

### log — 記錄指定玩家的所有指令（L_DEI）
```
log <玩家名稱>
```
開啟/關閉對該玩家的詳細指令記錄。

### force — 強制玩家執行指令（L_DEI）
```
force <玩家名稱> <指令>
force all <指令>
```
強制讓玩家執行某個指令（神族等級高於對方才能執行）。
