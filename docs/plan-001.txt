Key Changes
以「能完整啟動到進遊戲」為目標，逐一清理目前仍會在 boot 階段報錯的非區域資料。
優先處理順序改為：
data/gift.txt
其他 data/*.txt 內仍引用不存在 Object / Room / Mob 的資料
board/、etc/、其他 boot 時會被讀入的索引檔
每修一輪都重新前台啟動 src/merc，直到不再出現新的 Load_* boot 錯誤為止。
保持目前正式世界號段不再變動：
10000-10999 = changan
11000-11999 = xuchang
12000-12999 = academy
13000-13999 = drillground
Implementation Changes
清查所有 boot-time 資料檔中的舊引用，特別是：
data/gift.txt
data/sale.txt
data/ship.txt
data/bus.txt
board/*/index
修正原則固定如下：
若引用的是正式世界已存在的共用物件或房間，改為對應現存 VNUM
若引用的是已刪除舊區專屬內容，改成正式區已有的等價內容，或直接移除該條目
不再把舊 loyang / beiping 的號碼直接沿用到新世界
建立一份 boot 檢查清單，之後每次正式區調整都固定跑：
全區 mob/obj/roo 重複 VNUM 掃描
python scripts/check-data.py
前台啟動 src/merc ./src/merc.ini
檢查 debug/bugs、debug/error
補強技能文件：
merc-area-builder 已經納入一區一千位段與 directory.lst 註解規則
後續若還有常見 boot 錯誤模式，可再補進 merc-local-ops 或 mud-source-explainer
