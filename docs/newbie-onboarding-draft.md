現版新手入門文件草案（P4-T1）

定位
- 這份文件是給「剛離開學宮、準備進正式世界」的新角色。
- 內容以現版可直接操作為主，不依賴外部網站。

一、你現在在哪裡？
- 新角色會從 `500`（時空隧道）開始。
- 建議先往 `north` 進 `academy` 做完整教學，再回 `500` 往 `down` 進長安 `10001`。

二、離開學宮後的第一輪流程（照做即可）
1. `area`
   - 先看可去區域，避免盲走到高風險地點。
2. `find trainer` / `find shaman` / `find 小將`
   - 找訓練與轉職 NPC。
3. `train <trainer> <str|int|wis|dex|con>`
   - 把訓練點轉成屬性，先提升生存能力。
4. `rebirth <target>`
   - 十級前後完成第一次轉職。
5. `recall set`
   - 先設回城點，再外出練功。

三、1-30 級建議路線（現版）
- 1-10：`academy` / `drillground` 低段（迷路可 `new` 回訓練區）
- 10-20：長安 `10001` 承接 + `drillground` 補練
- 20-30：長安與許昌雙城循環
  - 先到長安車站 `10086`
  - 使用 `bus` 往返 `長安春水站 <-> 許昌驛站`

四、重要提醒（現版規則）
- `drillground` 是「新手試煉 + 對戰」混合區，不是純安全區。
- 進新地圖前先 `area`，找 NPC 先 `find`，再決定是否要深入。
- 不熟路時，先回主城補給與整備，不要硬撐。

五、你可以再看哪些 help
- `help newbies`
- `help getstart`
- `help classrebirth`
- `help trainattr`
- `help travel`
