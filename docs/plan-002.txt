結論是：

- 現版 `drillground` 幾乎完整承接舊版 `newfight` 的房間與怪物骨架。
- 已修復的 `bore / touch / pray / pull` 互動，方向符合舊版「look keyword -> 特殊動作」設計。
- 目前真正的缺口不在房間數量，而在：
  - 新手練功區與 PvP/校場被合併後的定位不夠清楚
  - 新手離開教學區後的主城承接、升級引導與世界導覽不足
  - 舊版網站中存在、但現版遊戲內未明確承接的玩家知識與成長節點

Comparison
一、已承接的舊功能

- 舊 `new` 的 450-477 教學線，現版以 `academy` 12001-12028 承接，房間結構、教學主題、怪物與商店規模基本一致。
- 舊 `newfight` 的 1201-1295 練功線，現版以 `drillground` 13001-13095 承接，房間結構、怪物密度與等級分層基本一致。
- `Room School = 500`、新角色先進時空隧道、再往北進教學區、往下進正式世界，已修回接近舊版邏輯。
- `look hole -> bore hole` 已可用，並可通往後續試煉區。
- `touch stone`、`pray`、`pull bar` 等舊式關鍵字互動已補回，不再只是誤導文案。

二、尚未完整承接的舊功能

1. 新手練功區與 PvP 區的定位被混合
舊版 `newfight`：
- `Upper 15`
- `NewHand Yes`
- 主要用途是新手練功

現版 `drillground`：
- `Upper LEVEL_PC`
- `Pk Yes`
- `Fight Yes`
- 區域描述改成「整合舊有練功、切磋與對戰用途」

這代表現版雖保留了舊房間，但玩法定位已從「低等級安全訓練場」改成「新手試煉 + 對戰校場混合區」。
需要補明確規格：
- 這裡是否仍是 1-15 級保護區
- 高等玩家是否應繼續能自由進入
- PvP 規則是否應與新手訓練區切開

2. 舊版網站中的新手升級承接未內建到遊戲導引
網站資料顯示：
- 新手區只是 1-10 或 1-15 的起點
- 離開後會進主城，再依等級轉往其他區
- `area`、`find`、`recall`、`rebirth`、`train` 是後續成長核心

現版遊戲內目前已經能走：
- `500 -> academy -> changan`

但尚未明確承接：
- 長安作為「離開教學後第一主城」的明確導引
- 10 級轉職 NPC 的導覽與提示
- 10-30 級練功路線的遊戲內提示
- `area` / `find` / `recall set` 的新手引導

3. 舊版多出生地主題已簡化成單一主城，但缺少新的說明文本
舊網站某些時期曾出現多出生地選單，但你目前已決定回到「單一合理出生主城」模式，這是正確的。
不過現版仍缺：
- 創角/新手 help 中對「為什麼只剩長安」的自洽說明
- 書院學宮與長安之間的世界觀承接文案

4. 新手區的玩家知識承接不足
`newhand` 文章中高頻出現的內容包括：
- `enable`
- `flee`
- `area`
- `find`
- `pry`
- `leftskill`
- `train`
- `rebirth`
- `recall`
- `bus` / `ship`
- `realm`

現版 `academy` 仍偏重早期的房間指令教學，但缺少：
- 「離開學宮後先做什麼」的明確教學
- 「10 級後去哪裡」的遊戲內導引
- 「加入國家 / 陣營」何時該開始的提示

5. 需確認的規則差異
舊版 `newfight` 描述提到：
- 怪物等級均在 15 級以下
- 若怪物比你高很多，你無法攻擊

現版 `drillground` 雖保留怪物分層，但尚未重新驗證：
- 是否仍有低等級保護規則
- 是否仍限制高等角色對低等怪的互動方式
- 是否因 `Pk/Fight` 設定改變而影響原本新手安全性

Gap Matrix
高優先缺口：

- `drillground` 的新手區與 PvP 區定位未正式定義
- 長安出城後的 10-30 級成長引導未內建
- `area` / `find` / `recall` / `rebirth` / `train` 缺少從新手區到正式世界的承接教學
- 新手離開學宮後的下一步缺少系統內提示

中優先缺口：

- 新手 help / welcome / motd / 房間文案仍未完全改成「長安版」世界觀
- 國家/realm 的引導尚未在適當等級節點浮現
- 類別導向的新手建議尚未整理成現版主城與 NPC 配置

低優先缺口：

- 舊版多篇玩家文章中的 alias、裝備修理、拍賣文化等便利知識尚未轉成現版說明文件
- `academy` 與 `drillground` 的部分舊文案仍可再潤飾，使其更貼合現版命名

Implementation Plan
Phase 1: 定義新手區與校場邊界

- 決定 `drillground` 是否維持「新手練功 + PvP 混合區」。
- 若否，拆成：
  - 低等級新手試煉區
  - 獨立 PvP / 切磋入口
- 重新檢查 `Upper`、`Pk`、`Fight`、`NewHand` 的組合是否符合預期。
- 補一份規則說明，避免玩家把校場當成出生地或主城的一部分。

Phase 2: 建立正式世界承接導引

- 在 `academy` 終點或 `500` / `12025` / `12026` 一帶補：
  - 前往長安後的建議步驟
  - `train`、`rebirth`、`area`、`find`、`recall` 基本提示
- 在 `10001` 或長安主城入口補：
  - 新手轉職、訓練、交通、回學宮的導引
- 補一份現版新手 help，對應舊 `newhand/newbies` 與 `players/newplayer` 的核心內容。

Phase 3: 建立 1-30 級世界導覽

- 以現版區域為準，重新整理：
  - 1-10 級：academy / drillground
  - 10-20 級：長安周邊與現存低等區
  - 20-30 級：下一層正式區
- 若現版缺少舊版對應的低中等區，列為內容擴充需求。
- 將路線寫入：
  - help 文件
  - 新手房間文案
  - 長安入口告示或導師 NPC 對話

Phase 4: 用網站資料重建玩家成長文件

- 以 `newhand-index.md` 為索引，整理現版對應版的：
  - 新手入門
  - 升級路線
  - 屬性與訓練
  - 轉職
  - 交通與 recall
  - 國家/realm 入門
- 先求「內容正確且可玩」，再決定要放成：
  - help 檔
  - 房間文案
  - 看板文章
  - 網站文件

Phase 5: 新區與中期內容補完

- 若 10-30 或 30-50 級現版路線明顯斷層，依網站與舊版地理規則規劃補區。
- 優先補：
  - 主城周邊低中等冒險區
  - 可對應舊網站常提及升級城市的現版替代區
  - 轉職、訓練、交通服務完整的一級主城生態

Codex Web Execution Mode
目標

本節的目的，是讓本計畫可以直接交給 Codex Web 之類的 AI coding agent 分階段實作，
並且在每一步完成後：

- 更新 `docs/plan-002.txt` 的進度
- 輸出本輪變更摘要
- 產生「下一步可直接複製貼上的 prompt」

執行原則

- 一次只做一個 Task，不跨 Phase。
- 每次實作都必須先讀：
  - `docs/plan-002.txt`
  - `docs/newhand-index.md`
- 若可以存取外部 skills，再補讀：
  - `H:\repos\.agents\skills\sango-mud-website-reference\references\newhand-index.md`
- 若任務牽涉新手流程、文案、隱藏指令或升級承接，必須對照：
  - `H:\repos\merc-fju-2.0-utf8-origin\area\new`
  - `H:\repos\merc-fju-2.0-utf8-origin\area\newfight`
  - `H:\repos\3yWebsite\newhand\players\newplayer\*.html`
- 不做大範圍重構；優先做小步可驗證修改。
- 每一步完成後，要把狀態寫回本檔，不只回覆聊天訊息。

Progress Update Format
每完成一個 Task，AI 都要在本檔最後方的 `Execution Log` 補一筆，格式固定如下：

- Date: `YYYY-MM-DD`

- Verification:

- Next Prompt:
  - 下一步建議交給 AI 的 prompt
